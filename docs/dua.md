# 对圈 Dua

门户游戏中心的新游戏。规则写在本文；实现在 `/game/dua/`。

参考了用户给的两张圆形对战截图（双方面孔、顶栏两排心、场上枪与伸手抓心），但**不是** PIXLOOP，也不使用其商标、水印或账号名。

## 和 Jev 的结论

- 先做 **玩家 vs CPU**，不做联机双人。
- 正式名：**对圈 / Dua**（日文：デュエル円）。大厅代号 `DUA`。
- 伸手抓心纳入第一版：捡心回血，拍到对手扣 1 心。
- 大厅登录拦截、返回、暂停、START、禁止系统选中/长按菜单，与挡板迷宫同一套壳。

## 场地

- 黑底、白色细圆环。角色不得出圈，撞边弹回。
- 红方面孔 = 玩家；黄表情 = CPU。
- 顶栏两排心：红 10、黄 10。某排到 0 则该方落败。

## 道具

场上随机刷出，碰到即拾取（武器替换旧武器）：

| 道具 | 效果 |
|------|------|
| 手枪 | 射速快，命中 −1 心 |
| 火箭筒 | 射速慢，命中 −2 心 |
| 红心 | 拾取或伸手抓到：自己 +1 心（不超过 10） |

伸手：短臂伸出。抓住红心则收回治疗；臂端打到对手则对方 −1 心，自己不治疗。

## 操作（手机 / 网页）

- 在圈内或下方控制区拖动：玩家朝指针移动。
- **FIRE**：有枪时朝对手自动瞄准开火。
- **GRAB**：伸手。靠近红心或对手时有效。
- 暂停不计入对局时间。不显示任何参考品牌。
