# 对圈 Dua

门户游戏中心的新游戏。规则写在本文；实现在 `/game/dua/`。

参考了用户给的圆形对战截图，但**不是** PIXLOOP，也不使用其商标、水印或账号名。

## 和 Jev 的结论

- 先做 **玩家 vs CPU**，不做联机双人。
- 正式名：**对圈 / Dua**。大厅代号 `DUA`。
- 开局后**不能控制路径**，只控制瞄准方向和开火。双方靠撞圈、互撞、中弹做物理反射。
- 头像是裸 emoji，不套圆底。开战前必须先选头像。
- 大厅登录拦截、返回、暂停、禁止系统选中，与挡板迷宫同一套壳。

## 开战前

从头像表里点一个 emoji。CPU 随机拿一个不同的。未选头像不能 START。

## 场地与运动

- 黑底白圈。角色是纯 emoji（碰撞半径仍在，不画椭圆底）。
- 开局各自带初速度。之后只做弹性碰撞：
  - 碰到圆周，按接触点法线反射；
  - 双方碰到，互相弹开；
  - 被子弹或刀子打中，沿弹道再弹一次。
- 玩家和 CPU 都**不能改自己的走位**。
- 顶栏两排心：玩家 10、CPU 10。到 0 落败。

## 操作

- 在圈里拖：只改**瞄准方向**（武器朝向），不改位移。
- **FIRE**：按当前瞄准开火。没有武器或弹药用尽则无效。
- 没有抓取、没有摇杆走位。

## 武器

撞到地上的图标即装备（替换旧武器）。图标约为头像大小的 **80%**。

| 武器 | 弹药 |
|------|------|
| 手枪 | 单发，共 5 发 |
| AK | 每次 3 发扫射，可扣 2 次 |
| 火箭筒 | 1 发 |
| 刀子 | 近战 1 次 |
| 霰弹枪 | 可打 2 次，每次 3 发散射 |
| 红心 | 撞到 +1 心（不超过 10） |
