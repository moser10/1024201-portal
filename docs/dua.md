# 对圈 Dua

门户游戏中心的新游戏。规则写在本文；实现在 `/game/dua/`。

参考了用户给的圆形对战截图，但**不是** PIXLOOP，也不使用其商标、水印或账号名。

## 和 Jev 的结论

- 先做 **玩家 vs CPU**，不做联机双人。
- 正式名：**对圈 / Dua / ガツン**。大厅代号 `DUA`。
- 开局后**不能控制路径**，只控制瞄准方向和开火。双方靠撞圈、互撞、中弹做物理反射。
- 头像是裸 emoji，不套圆底。开战前必须先选头像。
- 大厅登录拦截、返回、暂停、禁止系统选中，与打砖块同一套壳。

## 开战前

从头像表里点一个 emoji。CPU 随机拿一个不同的。未选头像不能 START。

## 场地与运动

- 黑底白圈。角色是纯 emoji（碰撞半径仍在，不画椭圆底）。
- 开局各自带初速度。之后只做弹性碰撞：
  - 碰到圆周，按接触点法线反射；
  - 双方碰到，弹性弹开并取消加速，路线尽量岔开；
  - 被子弹或刀子打中，沿弹道再弹一次。
- 碰到圆周必须弹离圈心方向，**不能贴边滑、也不能贴边连弹**。
- 中枪有短后坐力，结束后速度回到原来的巡航速度。
- 双方碰到做弹性分离，取消闪电加速，并略偏开以免马上再撞。撞圈后的反弹也会躲开对方。头像约为原来的 1.3 倍，场上资源约为原来的 3 倍。
- 场上道具图统一用 `/icons/weapon/` 原创图：`pistol.png` 手枪（原稿 glock）、`ak.png`、`rpg.png`、`sg.png` 霰弹、`knife.png`、`heart.png` 血、`boost.png` 加速。
- 游戏页只留标题 DUA，不要副标题。
- 松手开火会短时记住；若松开时刚捡到枪，仍会打出，不再空放一次。
- 顶栏两排心：玩家 10、CPU 10。到 0 落败。

## 场地形状

赛场是**正圆**（画布正方形 + 等半径），不是被 CSS 拉扁的椭圆。圆下方另有一块和打砖块类似的下巴控制区。

## 操作

- 下巴正中**摇杆**：拖动瞄准，**松手立刻开火**。旋钮行程有固定半径，跟手插值，松手回中。
- 瞄准线是细白虚线，始终沿上次有效方向，开火也用这个方向。
- 没有吃到武器、或弹药为 0，松手也不会开火；刚捡到枪时仍会补打一发。
- 所有武器都是射出弹体：手枪 / 刀子各 1 发，AK / 霰弹一次打出 3 发。没有近战判定，也不做手机震动。
- 不能控制自己的路径。
- 一句简单提示，中 / 英 / 日，跟门户 `portal_lang` 同步。

## 武器

撞到地上的图标即装备（替换旧武器）。图标约为头像大小的 **80%**。

| 武器 | 弹药 |
|------|------|
| 手枪 | 单发，共 5 发 |
| AK | 每次 3 发扫射，可扣 2 次 |
| 火箭筒 | 1 发 |
| 刀子 | 飞刀 1 发，和手枪同一套射击 |
| 霰弹枪 | 可打 2 次，每次 3 发散射 |
| 红心 | 撞到 +1 心（不超过 10） |
| 闪电加速 | 撞到后自身速度特快，约 5 秒 |

基础弹跳在 262 上再快 **45%**。撞到圆周同一弧段第二次起，反射角按 **+5°** 递增（0° / 5° / 10° / 15° 循环），仍保持弹回圈内。撞击处有闪光和火花。头像与道具用 Noto / Segoe / Apple 都能显示的 emoji，兼顾安卓。
