# 开房 Rooms

门户六象限最后一格。只给**已注册登录**的用户用。对圈联机同步还没接，这一期只做大厅。

## 入口

- 中：开房
- 英：Rooms
- 日：ルーム
- 图标：半开的门（房间，不是房子）

未登录会去 `/game/register/?return=rooms/`。

## 大厅

`/rooms/` 两栏：

- **游戏开房**：点「游戏」出一层很轻的列表，对圈默认打勾。不用系统 select（iOS 会弹出很大的滚轮）。人数由游戏决定（对圈最多 3 人）。按钮文案是「开房 / Get a room / 休憩する」。
- **聊天开房**：不限人数。

左上角用 `/js/navBack.js`：开房列表是「返回大厅」，房间里「返回开房」只回列表，不会再自动进房。只有从房间点「练习」进对圈，左上角才是「返回xxxx房间」。

列表和房间里只显示房间名，不显示后台房号。房主点「关闭房间」并确认后，房间关闭，聊天记录一起删。只离开不关房，记录还在。

## API

`/api/openroom`，表在 `open_rooms` / `open_room_seats` / `open_room_msgs`。

对圈房间这一期先做 **准备 + 房主开始**（Jev 选 ready_start）。点开始后进对圈页，物理暂时仍是本机 vs CPU。权威同步和 WebSocket 下一刀。
