# 开房 Rooms

门户六象限最后一格。只给**已注册登录**的用户用。对圈联机同步还没接，这一期只做大厅。

## 入口

- 中：开房
- 英：Rooms
- 日：ルーム
- 图标：半开的门（房间，不是房子）

未登录会去 `/game/register/?return=rooms/`。

## 大厅

`/rooms/` 两栏：

- **游戏开房**：先只开对圈，2 或 3 人。
- **聊天开房**：同一套座位和发言。

可建房、列房间、口令（4 位数字）、等候室聊天。房主离开即关房。游戏房里可以链到单机 `/game/dua/` 练习。

## API

`/api/openroom`，表在 `open_rooms` / `open_room_seats` / `open_room_msgs`。
