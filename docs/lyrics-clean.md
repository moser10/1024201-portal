# 找歌词：打印排版与歌词清洗

给 Ethan / Lin。这次只动「找歌词」的清洗和打印，没有改同步服务，没有部署，没有合并。

Jev MCP 在这台环境里不存在（没有 `~/.cursor/jev.json`，也没有 `jev` 工具）。清洗没有调用模型，规则写在 `js/lyricsClean.js` 里，可以逐条对。

## 根因

先看代码和线上歌词，再改。

打印页是 `tools/lyrics/view.html`。歌名在 `.view-title-row h1`，歌词在 `.view-lyrics`。打印样式原来把标题行的下边距写成 `2mm`，不到一行。打印按钮用 `display: none` 拿掉之后，标题仍挂在 flex 行上，没有单独把标题做成整行居中。

歌词在接口里走 `functions/api/portal.js` 的 `cleanLyricsText`。旧实现有两处会漏：

1. 时间戳正则是 `\[\d{1,2}:\d{2}(?:\.\d{2,3})?\]`。小数位必须是 2 或 3 位，或者完全没有小数。`[00:38.0]` 这种一位小数匹配不上，会留在正文里。`stripSynced` 用的是更窄的 `\[\d{2}:\d{2}\.\d{2,3}\]`，同样留不住一位小数。
2. 署名用「行首是不是这些词」来删整行，词表里有 `吉他`、`鼓`、`OP`、`Cover`。`吉他声在夜里响起`、`Open your eyes` 会被误伤。反过来，`主唱:`、`贝司:`、`萨克斯:`、`编程 :` 不在词表里，尾巴上的署名删不掉。清洗函数也不接收当前歌名和歌手，所以分不出「汪峰 - 再见青春」这种片头，和后面真正唱出来的「再见 青春」。

空行以前会被全部丢掉，段落没有了。

## 规则

实现在 `js/lyricsClean.js`。`functions/api/lyricsClean.js` 只做再导出。接口和打印页用同一份。

时间戳在全文去掉，不限行首：`[mm:ss]`、`[mm:ss.s]`、`[mm:ss.ss]`、`[mm:ss.sss]`，方括号可以是全角，括号里可以有空格，同一行可以有多个，也可以夹在字中间。`<mm:ss.s>` 同样去掉。旁边的字保留。`[ar:]` `[ti:]` `[offset:]` 这类 LRC 头信息也去掉。

整行删掉，只在形状对得上的时候：

- 角色名后面紧跟 `:` 或 `：`，后面是短名字。角色包括作词、作曲、编曲、主唱、演唱、吉他、贝司、贝斯、鼓、键盘、萨克斯、编程，以及 `Guitar:`、`Lyrics:`、`Produced by`、`Feat.`。
- `作词/作曲：某人` 这种多角色一行。
- `歌名：`、`Title:` 这种标签行。
- `【作词】汪峰`。
- 括号里只有角色，或只有「角色：人名」，或只有副歌/主歌/Chorus 这种段落标记。`（我抱着吉他）` 不是这种形状，整段保留。
- 行尾的 ` 吉他：周笛` 会剪掉，前面的唱词留下。行首 `吉他：周笛 我抱着吉他` 会留下后半句。
- 法律声明和厂牌行仍按原来的范围删。单独的英文单词 `Music` 不再当作厂牌后缀。

歌名和歌手只用来认片头，不拿去扫全文：

- `歌手 - 歌名` 或 `歌名 - 歌手`，分隔符是 `-`、`—`、`/` 这一类，并且两边对得上当前 title/artist，才算片头条。标点和空格不影响这层比较，但「再见 青春」不会因此等于拿去删正文。
- 片头里如果还有署名、上面的横幅，或者同时有一行歌名和一行歌手，这些片头行删掉。
- 片头里单独一行歌名，下一行已经是唱词，这行保留。上面即使有 `作词：` 也保留，避免把真正的第一句删掉。
- 正文里再次出现歌名，包括 `再见 青春`，保留。

空行保留。连续超过一个空行收成一个。署名行删掉后不额外插空行。

打印：标题整行居中，`margin: 0 0 1.15em`（12pt 标题的一行）。导航和打印按钮继续隐藏。打印底改成白纸。两栏歌词是原来的版式，没改。

`portal.js` 在网易云、LRCLIB、搜索结果这几条返回歌词的路上把 title/artist 传进去。`stripSynced` 改用同一套时间戳函数。`tools/lyrics/view.js` 显示前再洗一次，旧的 session 缓存也会被洗。洗两次结果不变。

## 局限

- 整行是 `鼓：一声巨响` 这种「单角色加冒号加不超过四个汉字」时，会当成署名删掉。`鼓声阵阵`、`我抱着吉他`、`吉他声在夜里响起` 没有这个冒号结构，会留。
- 一行中间如果署名没有括号、后面还连着唱词，为了不把后半句剪掉，这一处会留着。括号里的署名和行尾的署名会剪。
- 只有歌手名、旁边没有歌名横幅也没有署名时，这一行当唱词留着。
- 英文整行如果长得像 `Guitar: John Smith`，会删。普通句子 `Cover me`、`Open your eyes` 会留。
- `scripts/standalone/` 里的旧副本没有接这套清洗。线上门户走 `functions/api/portal.js`。
- 副歌、主歌这类标记只在括号里删。单独成行的不删。
